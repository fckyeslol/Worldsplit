Worldsplit is a 2D platformer built in Godot 4 focused on responsive movement and simple combat. The goal of the project has been to make the controls feel smooth and consistent rather than adding too many mechanics. The player can move with W,A,S,D, do a SUPER Jump with E, and attack using a double left click.

One of the main recent changes was replacing the roll with a vertical movement, turning it into a quick upward boost instead of a horizontal dodge. I also added a new enemy, a floating eye, to introduce a different type of threat compared to ground enemies. The game includes a basic health and stamina system, and the level resets when the player dies.

To run the project locally, install Godot 4, import the project using the project.godot file, and run it from the editor. For the web version, here is the link to itch.io so you can try it out!

https://fckyeslol.itch.io/worldsplit
